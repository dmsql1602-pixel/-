BAEK EUNBI Portfolio Prototype

구성
- index.html : 홈페이지 구조
- styles.css : 반응형 스타일
- script.js : 모바일 메뉴, 현재 섹션 표시, 이메일 복사
- 이력서_백은비.pdf : 이력서 보기/다운로드 버튼 연결 파일

실행
1. 압축을 풉니다.
2. index.html을 더블클릭해 브라우저에서 엽니다.
3. 별도 서버나 라이브러리가 필요하지 않습니다.

구현 특징
- PC / 태블릿 / 모바일 반응형
- Sticky header
- 섹션 앵커 내비게이션
- 모바일 햄버거 메뉴
- Resume PDF 보기/다운로드
- mailto 이메일 연결
- 이메일 복사 버튼
